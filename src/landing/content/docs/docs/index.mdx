## What is Relego?

Relego is a free, self-hosted way to revisit the passages you highlight while
reading. It imports highlights from your Kindle or Kobo, selects a small set
with spaced repetition, and delivers them back to your reader or inbox.

Your highlights stay on your own hardware. There is no account, subscription,
or cloud service involved.

![Relego's Library page showing imported books, authors, highlight counts, and recap status.](/images/docs/relego-web-library.webp)

## Set up your first recap

The shortest path is four actions in the web interface. You will need a Kindle
or Kobo highlight file, a place to run Docker, and an SMTP relay. The
[smtp4dev demo profile](/docs/reference/environment/#a-working-example) is
there if you want to test delivery before choosing a relay.
