## P1 — significant

1. **No maximum width on `.view`.** At 2560px the highlight quote ran to 2266px and the
   weight pips sat 1505px away from the text they belong to. The row read as two unrelated
   objects.
2. **Mobile dropped Highlights and the command palette.** The tab bar carried four items and
   the palette trigger was hidden below 900px, so the highlight list — the core surface —
   was unreachable on a phone, and the primary action surface with it.
3. **"Send recap now" fired with no destination configured**, producing a raw server error;
   and the next-recap time was rendered on the browser clock but labelled with the server's
   timezone name.

## P2 — worth doing

4. **Permanent delete with no confirmation.** `DELETE /highlights/{id}` is a hard delete with
   no restore endpoint, but the UI offered an undo toast it could not honour.
5. **Three save buttons on Settings** with no indication of which fields each one covers.
