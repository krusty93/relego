# Relego documentation

Welcome to the Relego documentation.

**Relego** is a self-hosted tool that sends your Kindle and Kobo highlights back to your Kindle (or inbox) as EPUB recaps — so what you've read sticks.

## In this documentation

- **[Getting started](getting-started)** — run the server and web UI, import your first highlights, configure delivery
- **[CLI reference](cli)** — manage Relego from the terminal without a browser
- **[Architecture](architecture)** — how the components fit together
